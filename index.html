Morse Code Quick Reference

This page is a compact cheat sheet for International Morse code. It lists every letter and digit, explains the timing that turns dots and dashes into readable signals, and shares a few habits that make learning easier. If you want to convert text instantly, use the free Morse code translator at QuickMorse.

Timing rules

ElementLength
Dot (dit)1 unit
Dash (dah)3 units
Gap inside a letter1 unit
Gap between letters3 units
Gap between words7 units

Timing matters more than speed. A clean 1:3:7 rhythm is what lets a listener tell ET apart from A.

Tips for learning faster

  • Learn by sound, not by reading dots and dashes. Hearing "di-dah" builds instant recognition.
  • Start at a character speed of around 20 WPM with wide gaps between letters (the Farnsworth method), then close the gaps as you improve.
  • Practise in short daily sessions of 10–15 minutes instead of one long session.
  • Test yourself with interactive Morse code practice drills, and check recordings with an audio decoder.
